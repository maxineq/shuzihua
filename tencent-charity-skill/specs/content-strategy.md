# 腾讯公益机构平台 - 文案内容规范

> 参考有赞 Zan Design 内容策略，结合本平台业务场景定制

---

## 1. 三大基础原则

### 准确性
- 内容表达准确，无歧义，不模糊
- 避免错别字，确保词汇规范
- 英文大小写遵循规范：产品缩写用大写（API、ID、CDN），专有名词保留原格式（iOS、SaaS、OpenID）
- 人称代词统一使用"你"，不使用"您"（除协议/法律文本）
- 避免在同一句式中同时使用"你"和"我"
- 根据场景与用户类型提供有价值的信息

### 一致性
- 句式统一，不使用被动语态，简化表达
- 产品用词保持一致，功能名称全平台统一
- 数据格式规范：使用阿拉伯数字（3条）而非汉字（三条）
- 计量单位使用国际制英文缩写（kg、km）
- 相同功能在不同页面使用相同文案

### 易读性
- 精简信息，不重复表达用户已知信息
- 通过段落、列表、空格实现结构化组织
- 使用字号、行高、间距区分信息层级
- 一句话说清一件事，避免长句嵌套

---

## 2. 语气语调

### 整体风格
- **专业但不冰冷** — 用简洁明确的语言，不用官腔
- **平和且克制** — 保持冷静，尽量不使用感叹号
- **引导而非命令** — "建议你..."而非"你必须..."
- **积极而非消极** — 说"可以做什么"而非"不能做什么"

### 示例对比

| ❌ 不推荐 | ✅ 推荐 | 原因 |
|---------|--------|------|
| 你没有填写必填项！ | 请填写必填项 | 避免指责语气 |
| 操作失败！！！ | 操作失败，请稍后重试 | 克制，不用多个感叹号 |
| 您确定要删除吗？ | 确认删除此项目？删除后不可恢复 | 说明后果比反问更有效 |
| 不允许上传超过5M的文件 | 请上传不超过 5MB 的文件 | 积极正面表述 |
| 系统出错了 | 网络异常，请稍后重试 | 给出可操作的建议 |

## 3. 场景文案规范

### 3.1 按钮文案

**规则**:
- 使用动词或动词+名词结构
- 2-4个字为佳，最长不超过6个字
- 主按钮文案应与页面标题/操作目的对应

| 场景 | 推荐文案 | 不推荐 |
|------|---------|--------|
| 新建 | 新建项目 / 新增 | 创建一个新项目 |
| 提交 | 提交 / 提交审核 | 确定提交 |
| 保存 | 保存 / 保存草稿 | 保存修改 |
| 编辑 | 编辑 | 修改信息 |
| 删除 | 删除 | 移除 |
| 取消 | 取消 | 算了 / 返回 |
| 确认 | 确认 / 确定 | OK / 好的 |
| 查看 | 查看 / 查看详情 | 查看更多信息 |
| 导出 | 导出 | 下载数据 |
| 筛选 | 筛选 | 搜索 / 查找 |
| 重置 | 重置 | 清空条件 |

### 3.2 提示文案 (Toast / Message)

**规则**:
- 简明扼要，一句话说清
- 成功提示可省略主语
- 错误提示需说明原因或给出建议

| 类型 | 格式 | 示例 |
|------|------|------|
| 成功 | 操作 + 成功 | "提交成功" / "保存成功" |
| 失败 | 操作 + 失败 + 原因/建议 | "提交失败，请检查网络后重试" |
| 警告 | 提示内容 + 建议 | "该备案号即将过期，请及时更新" |
| 信息 | 客观描述 | "数据已更新" |
| 加载中 | 操作 + 中... | "提交中..." / "导出中..." |

### 3.3 确认弹窗文案

**结构**: 标题 + 描述（可选） + 操作按钮

| 场景 | 标题 | 描述 | 按钮 |
|------|------|------|------|
| 删除 | 确认删除？ | 删除后不可恢复 | 取消 / 删除 |
| 批量删除 | 确认删除已选中的 X 条数据？ | 删除后不可恢复 | 取消 / 删除 |
| 提交审核 | 确认提交审核？ | 提交后将进入审核流程 | 取消 / 提交 |
| 离开页面 | 确认离开？ | 当前修改尚未保存 | 取消 / 离开 |
| 驳回 | 确认驳回？ | 请填写驳回原因 | 取消 / 驳回 |

**规则**:
- 标题用疑问句，结尾加问号
- 描述说明操作后果，不超过一句话
- 确认按钮用具体动词（"删除"而非"确定"）
- 危险操作的确认按钮用红色

### 3.4 空状态文案

| 场景 | 文案 | 操作引导 |
|------|------|---------|
| 列表无数据 | 暂无数据 | [新建XXX] |
| 搜索无结果 | 未找到相关结果 | 试试其他关键词 |
| 筛选无结果 | 没有符合条件的数据 | [清除筛选条件] |
| 无权限 | 暂无权限访问此页面 | 请联系管理员开通权限 |
| 功能未开通 | 该功能暂未开通 | [了解详情] |

### 3.5 表单文案

**标签 (Label)**:
- 使用名词或名词短语
- 2-6个字为佳
- 与业务术语保持一致

**占位符 (Placeholder)**:
- 输入框: "请输入" + 内容提示（如 "请输入项目名称"）
- 选择器: "请选择" + 内容提示（如 "请选择项目类型"）
- 搜索框: "请输入" + 搜索对象 + "进行搜索"

**帮助文字**:
- 说明格式要求: "支持 JPG、PNG 格式，单张不超过 5MB"
- 说明业务规则: "筹款目标需大于已筹金额"
- 用括号包裹补充信息: （选填）/（必填项以 * 标注）

**错误文案**:
| 错误类型 | 格式 | 示例 |
|---------|------|------|
| 必填为空 | 请输入/选择 + 字段名 | "请输入项目名称" |
| 格式错误 | 请输入正确的 + 字段名 | "请输入正确的手机号" |
| 超出限制 | 字段名 + 限制说明 | "项目名称不超过 50 个字" |
| 重复 | 该 + 字段名 + 已存在 | "该备案编号已存在" |
| 范围错误 | 字段名 + 范围说明 | "筹款目标需在 1-9999999 之间" |

### 3.6 状态文案

| 状态 | 展示文案 | 备注 |
|------|---------|------|
| 草稿 | 草稿 | — |
| 待审核 | 待公募审核 / 待平台审核 | 说明具体审核方 |
| 审核中 | 审核中 | — |
| 已通过 | 已通过 / 审核通过 | — |
| 已驳回 | 已驳回 | 需展示驳回原因 |
| 已上线 | 已上线 | — |
| 筹款中 | 筹款中 | — |
| 已暂停 | 已暂停 | — |
| 已结束 | 已结束 / 已结项 | — |

## 4. 标点符号规范

### 4.1 基本规则

| 规则 | 说明 |
|------|------|
| 功能性文本结尾 | 一般不加句号（标题、标签、Toast、按钮） |
| 提示文本结尾 | 表单下方提示文字需加句号 |
| 疑问句 | 加问号（确认弹窗标题） |
| 多句文本 | 句中有句号则结尾也需加句号 |
| 感叹号 | 尽量不使用，保持克制平和 |

### 4.2 中英文混排

| 规则 | 示例 |
|------|------|
| 中英文之间加空格 | "请输入 OpenID" ✅ / "请输入OpenID" ❌ |
| 中文与数字之间加空格 | "共 101 条数据" ✅ / "共101条数据" ❌ |
| 英文与数字之间不加空格 | "iOS14" ✅ |
| 全角标点用于中文语境 | "提交成功，请等待审核。" |

### 4.3 不使用的标点

- ❌ 多个感叹号 `!!!`
- ❌ 省略号表达犹豫 `...`（Loading 的 `...` 除外）
- ❌ 波浪号 `~`
- ❌ 非正式表情符号

## 5. 数据格式规范

### 5.1 数字

| 类型 | 格式 | 示例 |
|------|------|------|
| 整数 | 千位分隔符 | 1,234,567 |
| 金额 | ¥ + 千位分隔 + 两位小数 | ¥12,345.67 |
| 百分比 | 数字 + % | 68.5% |
| 序号 | 阿拉伯数字 | 第 1 步、共 3 条 |
| 计量 | 数字 + 空格 + 单位 | 5 MB、100 元 |

### 5.2 日期时间

| 场景 | 格式 | 示例 |
|------|------|------|
| 完整日期时间 | yyyy/MM/DD HH:mm:ss | 2024/08/12 16:44:12 |
| 日期 | yyyy/MM/DD | 2024/08/12 |
| 日期范围 | 日期 + 至 + 日期 | 2024/01/01 至 2024/12/31 |
| 相对时间 | X分钟前/X小时前/X天前 | 5 分钟前（24小时内可用） |

### 5.3 手机号/敏感信息

| 类型 | 格式 | 示例 |
|------|------|------|
| 手机号脱敏 | 前3后4 | 132****6688 |
| 身份证脱敏 | 前4后2 | 4401**********34 |
| 银行卡脱敏 | 后4位 | **** **** **** 1234 |
| 邮箱脱敏 | 首尾字符 | a****d@qq.com |

## 6. 平台专用术语表

### 6.1 统一用词

| 统一术语 | 不使用 | 说明 |
|---------|--------|------|
| 项目 | 活动/任务 | 公益项目的统一称呼 |
| 机构 | 组织/团体 | 公益机构 |
| 筹款 | 募捐/捐款(发起方角度) | 机构端用"筹款" |
| 捐赠 | 捐款(用户角度) | C端用户端用"捐赠" |
| 结项 | 关闭/结束项目 | 项目完成后的操作 |
| 备案 | 登记/注册 | 募捐方案备案 |
| 上线 | 发布/开放 | 项目通过审核后 |
| 驳回 | 拒绝/不通过 | 审核未通过 |
| 审核 | 审批 | 统一用"审核" |

### 6.2 功能名称统一

| 功能 | 统一名称 |
|------|---------|
| 项目管理 | 项目列表 / 项目详情 / 新项目上线申请 |
| 财务 | 项目财披 / 项目预算 |
| 审核 | 项目审核 / 专项基金审核 / 项目透明度审核 |
| 数据 | 一起捐数据 / 项目数据月报看板 |
| 设置 | 机构信息 / 成员管理 / 角色管理 |
