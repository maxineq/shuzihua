## 1. 布局体系

### 整体结构
| 区域 | 宽度 | 说明 |
|------|------|------|
| 整体画幅 | 1440px | 桌面端标准宽度 |

| Token | 值 | 用途 |
|-------|-----|------|
| --spacing-xs | 4px | 图标与文字间距 |
| --spacing-sm | 8px | 紧凑元素间距、表格单元格内上下间距 |
| --spacing-md | 12px | 标签间距、小模块间距 |
| --spacing-lg | 16px | 面包屑与标题间距、模块内间距 |
| --spacing-xl | 24px | 内容区边距、卡片内边距、模块间距 |
| --spacing-xxl | 32px | 大模块间隔 |

## 35. 设计原则总结

1. **扁平化**：无阴影设计，层次通过背景色和边框区分
2. **品牌红为主调**：核心操作、选中态、强调信息均使用 #ED3142
3. **信息密度高**：以表格为主要信息承载方式，适合B端管理后台
4. **标准 1440px 桌面端布局**：左导航 + 右内容区经典结构
5. **中性色克制**：仅使用黑色不同透明度做文字层级，不引入额外灰阶

## 36. 内容页排版规范（强制遵循）

内容区内的元素必须按以下**固定顺序**自上而下排列，不可跳过或乱序：

```
┌─────────────────────────────────────────────────────────────┐
│  ① 页面标题（20px Semibold, rgba(0,0,0,0.9)）                │
│     间距 32px ↓                                              │
│  ② Tab 标签页（可选，有多视图时出现）                           │
│     间距 32px ↓                                              │
│  ③ 筛选区（必须遵循 88px 间距规范，必须有查询+重置按钮）         │
│     间距 24px ↓                                              │
│  ④ 操作按钮行（如 "+ 新建XX"，可选）                           │
│     间距 24px ↓                                              │
│  ⑤ 数据展示区（表格 / 卡片网格）                               │
│     间距 0 ↓                                                 │
│  ⑥ 分页器（表格底部）                                         │
└─────────────────────────────────────────────────────────────┘
```

**各层级间距规则：**
| 从 → 到 | 间距 | 说明 |
|---------|------|------|
| 标题 → Tab / 筛选区 | 32px | 页面内组件默认间距 |
| Tab → 筛选区 | 32px | 页面内组件默认间距 |
| 筛选区 → 操作按钮行 | 24px | 关系较近的组件间距 |
| 操作按钮行 → 表格 | 24px | 关系较近的组件间距 |
| 筛选区 → 表格（无操作按钮时） | 24px | 关系较近的组件间距 |
| 卡片内元素间距 | 16px | 卡片内部元素间距 |

**间距三级体系（强制遵循）：**
| 级别 | 值 | 适用场景 |
|------|-----|---------|
| 页面级 | **32px** | 页面内独立组件之间（标题与Tab、Tab与筛选区、模块与模块） |
| 关联级 | **24px** | 关系较近的组件之间（筛选与表格、操作按钮与表格） |
| 卡片内 | **16px** | 卡片/模块容器内部元素之间（标签与值、行与行） |

**容器样式：**
- 外层白色卡片：`background: #FFFFFF; border-radius: 6px; padding: 32px; box-shadow: 0px 2px 1.5px rgba(0,0,0,0.1);`
- 标题：20px Semibold, `rgba(0,0,0,0.9)`
- Tab 选中态：品牌色文字 + 底部 3px 品牌色线条
- Tab 默认态：`rgba(0,0,0,0.6)` + 底部 1px `#E7E7E7`

**常用功能/快捷入口排版规则：**
| 功能数量 | 排版方式 | 图标尺寸 |
|---------|---------|---------|
| ≤ 4 个 | **左图标右文字**（横向，flex-direction: row, gap 16px） | 48px 圆形 |
| > 4 个 | **上图标下文字**（纵向，flex-direction: column, gap 12px） | 64px 圆形 |
