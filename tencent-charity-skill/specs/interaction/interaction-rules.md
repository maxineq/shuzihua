# 腾讯公益机构平台 - 交互规范 & 页面结构

## 1. 页面结构类型

平台共有 6 种标准页面结构，所有新页面必须基于以下模板之一构建：

---

### 01 业务集合页（列表页）

**定义**: 展示某类业务数据的集合视图，以表格为主要承载形式。

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏 (64px)                         │
├─────────┬───────────────────────────────┤
│         │ 面包屑导航                      │
│         │ 页面标题 + 操作按钮              │
│         │ ┌───────────────────────────┐  │
│ 左侧    │ │ Tab 标签切换               │  │
│ 导航    │ │ 筛选区（输入框+选择器）     │  │
│ 232px   │ │ 操作按钮组                  │  │
│         │ │ 数据表格                    │  │
│         │ │ 分页器                      │  │
│         │ └───────────────────────────┘  │
└─────────┴───────────────────────────────┘
```

**交互规则**:
- 筛选条件变更后，需手动点击"筛选"按钮触发，不自动刷新
- 重置按钮清空所有筛选条件并刷新列表
- 表格支持排序（点击表头）
- 操作列链接：单操作直接显示，多操作用"更多操作 ▾"下拉
- 分页切换不回到顶部（仅表格区域刷新）
- Tab 切换时重置筛选条件和分页

**适用场景**: 项目列表、留言管理、备案号管理、成员管理

---

### 02 业务详情页

**定义**: 展示单个业务对象的完整详细信息，以只读 Key-Value 布局为主。

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏                                │
├─────────┬───────────────────────────────┤
│         │ 面包屑 / ← 返回上一步           │
│         │ ┌───────────────────────────┐  │
│ 左侧    │ │ 头部概览卡片（进度/状态）  │  │
│ 导航    │ │ Tab 标签（基础信息/财务...）│  │
│         │ │ ┌─────────────────────┐   │  │
│         │ │ │ 信息模块标题 A       │   │  │
│         │ │ │ Key-Value 双列布局   │   │  │
│         │ │ ├─────────────────────┤   │  │
│         │ │ │ 信息模块标题 B       │   │  │
│         │ │ │ Key-Value / 表格     │   │  │
│         │ │ └─────────────────────┘   │  │
│         │ │ [编辑] 按钮（右下角）      │  │
│         │ └───────────────────────────┘  │
└─────────┴───────────────────────────────┘
```

**交互规则**:
- "返回上一步" 链接回到来源列表页
- Tab 切换不刷新页面，仅切换内容区域
- 长内容模块可折叠（Collapse），默认展开
- 敏感信息默认脱敏(****)，点击眼睛图标切换显隐
- "编辑"按钮跳转到对应编辑表单页
- 详情页头部可展示操作按钮（如"通过审核""驳回"）

**适用场景**: 项目详情、机构信息、成员详情、商户号详情

---

### 03 表单页

**分为两种子类型**：

#### 03-A 基础表单（单页表单）

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏                                │
├─────────┬───────────────────────────────┤
│         │ 面包屑 / ← 返回上一步           │
│         │ 页面标题                        │
│         │ ┌───────────────────────────┐  │
│ 左侧    │ │ 表单模块标题 + 说明文字    │  │
│ 导航    │ │ * 字段标签    [输入框]     │  │
│         │ │ * 字段标签    [选择器]     │  │
│         │ │ * 字段标签    [文本域]     │  │
│         │ │   字段标签    [输入框]     │  │
│         │ │                           │  │
│         │ │         [取消] [提交]      │  │
│         │ └───────────────────────────┘  │
└─────────┴───────────────────────────────┘
```

#### 03-B 分步表单（多步骤表单）

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏                                │
├─────────┬───────────────────────────────┤
│         │ 面包屑 / ← 返回上一步           │
│         │ ┌───────────────────────────┐  │
│ 左侧    │ │ ① ─── ② ─── ③ ─── ④     │  │
│ 导航    │ │ (步骤指示器)               │  │
│         │ │                           │  │
│         │ │ 当前步骤表单内容            │  │
│         │ │ ...                       │  │
│         │ │                           │  │
│         │ └───────────────────────────┘  │
│         │ ┌───────────────────────────┐  │
│         │ │ [AI工具] [上一步] [下一步] [保存] │
│         │ └───────────────────────────┘  │
└─────────┴───────────────────────────────┘
```

**交互规则（通用）**:
- 必填字段标签前有红色 `*`
- 实时校验：输入框失焦时校验，红色错误文字显示在输入框下方
- 提交校验：整体校验，滚动到第一个错误字段
- "取消" 有未保存内容时弹确认弹窗
- 表单数据自动暂存（刷新不丢失）

**交互规则（分步表单特有）**:
- 步骤指示器展示总步数和当前进度
- "下一步" 触发当前步校验，通过后才进入下一步
- "上一步" 自由回退，已填数据保留
- "保存草稿" 任何时候可保存当前进度
- 未完成当前步不可点击后续步骤编号跳步

**适用场景**: 
- 基础表单: 编辑信息、备案编辑、商户号申请
- 分步表单: 新项目上线申请(4步)、机构认证

---

### 04 沉浸式操作页（空白页/结果页）

**定义**: 脱离常规导航的全屏/简化页面，用于单一操作或结果展示。

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏（简化版/可隐藏侧边栏）         │
├─────────────────────────────────────────┤
│                                         │
│              居中内容区域                  │
│         （图标/二维码/结果文案）            │
│                                         │
│              [操作按钮]                   │
│                                         │
└─────────────────────────────────────────┘
```

**交互规则**:
- 无侧边栏或侧边栏最小化
- 内容居中显示
- 成功页自动倒计时跳转（可选）
- 提供明确的"返回"或"下一步"操作

**适用场景**: 登录/注册、协议签署、支付结果、二维码展示

---

### 05 分栏选择页/预览页

**定义**: 左右分栏，左侧列表选择，右侧展示对应内容预览。

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏                                │
├─────────┬──────────────┬────────────────┤
│         │ 左栏(列表)    │ 右栏(预览)     │
│ 导航    │ 搜索框        │ 预览内容       │
│         │ 可选列表项    │ 或详细信息     │
│         │ ✓ 选中项     │               │
│         │              │               │
│         │       [取消] [确认]           │
└─────────┴──────────────┴────────────────┘
```

**交互规则**:
- 左栏列表支持搜索/筛选
- 点击列表项，右栏实时预览
- 选中项有明显视觉标识（✓ 或高亮背景）
- 支持多选（checkbox）或单选（radio）

**适用场景**: 模板选择、协议预览、内容分类浏览

---

### 06 首页/数据看板页

**定义**: 平台首页或数据看板，以数据概览和快捷入口为主。

**结构模板**:
```
┌─────────────────────────────────────────┐
│ 顶部导航栏                                │
├─────────┬───────────────────────────────┤
│         │ 欢迎信息 / 机构名称             │
│         │ ┌─────┐ ┌─────┐ ┌─────┐     │
│ 左侧    │ │数据卡│ │数据卡│ │数据卡│     │
│ 导航    │ └─────┘ └─────┘ └─────┘     │
│         │ ┌───────────────────────────┐  │
│         │ │ 快捷操作入口               │  │
│         │ ├───────────────────────────┤  │
│         │ │ 待办事项 / 通知列表        │  │
│         │ └───────────────────────────┘  │
└─────────┴───────────────────────────────┘
```

**交互规则**:
- 数据卡片可点击跳转到对应列表页
- 数据实时刷新或定时刷新
- 待办事项可直接操作（如"去审核"链接）
- 通知列表按时间倒序

**适用场景**: 平台首页、数据中心

## 2. 通用交互模式

### 2.1 页面导航
| 模式 | 说明 |
|------|------|
| 面包屑 | 所有二级及以下页面必须有面包屑，可点击回到上级 |
| 返回链接 | 编辑/详情页用 "← 返回上一步" 蓝色链接 |
| Tab 切换 | 同一页面内切换视图，无页面跳转 |
| 侧边栏导航 | 一级/二级菜单，当前页高亮(红色文字+浅红背景) |

### 2.2 数据加载
| 状态 | 表现 |
|------|------|
| 加载中 | 区域级 loading spinner 或骨架屏 |
| 空数据 | 空状态插图 + "暂无数据" 文字 + 操作引导 |
| 加载失败 | 错误提示 + "重试" 按钮 |
| 部分加载 | 已有数据正常展示 + 加载区域 spinner |

### 2.3 操作反馈
| 操作 | 反馈 |
|------|------|
| 提交成功 | Toast 成功提示(绿色，1.5s 消失) 或 跳转成功页 |
| 提交失败 | Toast 错误提示(红色，2s 消失) + 表单错误标红 |
| 删除 | 二次确认弹窗："确认删除？此操作不可恢复" |
| 批量操作 | 选中数量提示 + 确认弹窗 |
| 保存草稿 | Toast 成功提示 "已保存草稿" |

### 2.4 弹窗交互
| 类型 | 触发 | 关闭方式 |
|------|------|---------|
| 确认弹窗 | 危险操作(删除/驳回) | 取消按钮 / × |
| 编辑弹窗 | 快捷编辑(不跳页) | 取消 / × / 提交成功自动关闭 |
| 详情抽屉 | 查看详情(不跳页) | × / 点击遮罩 |
| 提示弹窗 | 系统通知/警告 | 确认按钮 / × |

### 2.5 表格交互
| 交互 | 说明 |
|------|------|
| 排序 | 点击表头箭头，支持升序/降序/默认三态切换 |
| 筛选 | 表格上方筛选区，点击"筛选"按钮触发 |
| 选择 | 首列 checkbox，表头 checkbox 为全选/取消全选 |
| 展开行 | 点击行左侧展开箭头，显示子信息 |
| 行操作 | 操作列链接，hover 下划线 |
| 分页 | 底部分页器，支持切换每页条数 |

### 2.6 表单校验时机
| 时机 | 行为 |
|------|------|
| 失焦校验 | 单字段离开焦点时校验，即时反馈 |
| 提交校验 | 点击提交时全量校验，滚动到第一个错误 |
| 实时校验 | 字数限制实时更新计数器 |
| 联动校验 | 字段间有依赖时，相关字段同时校验 |

## 3. 页面间跳转规则

### 3.1 跳转方式
| 场景 | 方式 |
|------|------|
| 列表 → 详情 | 点击"查看"链接或行内项目名 |
| 详情 → 编辑 | 点击"编辑"按钮 |
| 列表 → 新建 | 点击"新建XXX"按钮 |
| 任意 → 上一页 | 面包屑或"返回"链接 |
| 操作完成 | 自动返回列表页（带成功Toast） |

### 3.2 数据保持规则
| 场景 | 规则 |
|------|------|
| 列表→详情→返回 | 保持之前的筛选条件和分页位置 |
| 编辑→取消 | 弹窗确认后返回，不保存 |
| 分步表单→刷新 | 恢复到上次保存的步骤和数据 |
| Tab切换 | 保持各Tab已加载的数据 |

---

## 4. 权限与状态交互

### 4.1 权限控制
| 无权限表现 | 说明 |
|-----------|------|
| 按钮禁用 | 灰色态 + 不可点击 + hover tooltip "无权限" |
| 菜单隐藏 | 无权限的菜单项直接不显示 |
| 页面拦截 | 无权限访问的页面展示"无权限"空状态 |

### 4.2 审核流程状态
| 状态 | 用户可操作 |
|------|-----------|
| 草稿 | 编辑、提交、删除 |
| 待审核 | 撤回 |
| 已通过 | 查看 |
| 已驳回 | 查看驳回原因、重新编辑并提交 |
| 已撤回 | 重新编辑并提交、删除 |
