# 美学评测研究库

这是一个部署到 GitHub Pages 的静态论文研究工具：GitHub Actions 自动收集论文元数据；公开仓库只保存论文元数据、摘要翻译和技术总结。完整译文不进入仓库，也不作为 Pages 静态资源发布。

## 部署

1. 在仓库的 Pages 设置中选择 GitHub Actions。
2. 推送到 main 会触发 Pages 部署；论文收集工作流默认每天 UTC 01:00（北京时间 09:00）运行。
3. 也可以在 Actions 中手动运行收集任务。

## 自动收集

数据源为 OpenAlex 公共 API，每次最多拉取 30 条结果，使用 DOI 或标题去重，并写入 `papers.json`。自动任务不会下载全文、调用 LLM 或生成翻译分析。仓库不使用 `LLM_API_URL`、`LLM_API_KEY`、`LLM_MODEL`。

## 公开内容与本机私密全文译文

- **公开内容**：`papers.json` 中的论文元数据、摘要翻译，以及 `analysis/` 中的技术总结；这些内容会随 GitHub Pages 发布。
- **仅本机私密**：点击页面“导入分析”后选择 Markdown，完整译文会保存到当前浏览器的 `localStorage`，并在 Page 详情中以“仅本机私密全文译文”展示。导入不会写入 GitHub，也不会上传到服务器。
- **隐私边界**：GitHub Pages 没有后端认证，无法做到真正的账号级“仅自己可见”；本方案只是浏览器本地保存，不是安全存储。换设备、换浏览器或清理站点数据会丢失译文；同一浏览器有权限访问该站点本地数据的用户也可能看到它。
- **操作约束**：不要把完整译文提交到 GitHub、`analysis/` 或任何公开静态资源；请仅导入你有权访问和处理的论文内容。建议公开发布摘要翻译、研究分析和必要的短摘录。

## 人工翻译与解析导入

1. 在首页点击“导入分析”，选择对话助手生成的 Markdown。
2. 页面会立即进行本地预览，并保存到当前浏览器；完整译文不会自动写回 GitHub。
3. 如需公开展示，只将摘要翻译、研究问题、方法/模型、数据集、评测指标、关键技术、实验结论、局限性和可迁移启示整理到 `analysis/`，然后更新 `analysis/README.md` 并提交推送。
4. 运行 `python3 analyze_papers.py` 可自动刷新公开分析索引。

## 版权与隐私边界

仅处理开放获取、授权访问或你明确有权使用的论文内容。翻译和解析应遵守出版社、作者、数据库及论文许可证条款；不要绕过付费墙，不要把受版权保护的整篇译文公开到仓库或 Pages。不要上传包含个人隐私或机密信息的材料。

## 论文原文链接字段与打开规则

`papers.json` 的原文相关字段如下：

- `openAccessLocation.url`：开放获取全文或开放存档页面；
- `openAccessLocation.pdf_url` / `pdfUrl`：可直接打开的开放全文 PDF；
- `landingPageUrl`：出版商或期刊的论文落地页；
- `url`：兼容旧数据的链接字段，作为出版商页面候选；
- `doi`：DOI 字符串或 DOI URL，作为最后兜底。

页面按“开放获取全文 → 出版商页面 → DOI 页面”优先级组织链接。所有链接在使用前只接受 `http`/`https` 协议，并显示来源类型与域名；确认后使用新标签页打开，不离开当前研究库。没有可用链接时显示“暂无可用原文链接”，并提供复制 DOI/论文标题操作。多个候选链接会按三类分组展示。
